class heed.sinks.StoreSink(store: MutableMapping[str, str])[source]

Persist each report as JSON into a dol-style store keyed by report id.

The zero-configuration default when no external sink (e.g. GitHub) is configured. store is any MutableMapping[str, str] (a plain dict, a dol file store, S3, …) — dependency-injected so the sink stays testable.
