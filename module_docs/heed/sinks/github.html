heed.sinks.github

A sink that turns a report into a GitHub issue.

The issue-creating call is dependency-injected (create_issue) so the sink is testable without network access and so the credential-brokering strategy (a GitHub App minting short-lived installation tokens, or a server-side token) is pluggable. A convenience factory builds a create_issue from a token via ghapi (lazy import, the heed[github] extra).

Hard platform limit (see misc/docs/design.md): there is no GitHub API to attach an image to an issue. Resolve a screenshot_url (committed-file / attachment-store URL) and embed it in the body; base64 data-URIs do not render.
