heed.storage

Storage helpers — dol-backed stores for reports and binary attachments.

Stores are plain MutableMapping``s, so the rest of heed never depends on a specific backend. Defaults are in-memory; pass a directory to persist to the filesystem, or inject any ``dol store (S3, Mongo, …).

heed.storage.make_attachment_store(rootdir: str | None = None) → MutableMapping[source]

A bytes store for attachments. In-memory unless rootdir is given.

heed.storage.make_report_store(rootdir: str | None = None) → MutableMapping[source]

A text store for report JSON. In-memory unless rootdir is given.
